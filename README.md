# Java Sorting Codes

Sorting algorithms implemented in Java as part of my DSA practice.

## Programs
- MergeSortArray: Merge sort on an array
- MergeSortLinkedlist: Merge sort on a linked list
- InsertionSortLinkedlist: Insertion sort on a linked list
- SortByGPA: Sorting student records by GPA
- SortingComparison: Comparing sorting algorithms
- ArrayParity: Array parity problem

## How to run
```
javac FileName.java
java FileName
```
